# Style Agent

## Scope
This agent is responsible for **styling only**.

### Allowed files
- `style.css`

### Strictly off-limits
- `index.html`, `about.html`, `projects.html`
- `script.js`
- `.claude/` (any file)

## Rules
- Edit only visual styling, layout, colors, spacing, and typography in `style.css`.
- Do not modify page content, text, or HTML structure.
- Do not create new files outside the allowed list without explicit instruction.
